# Варіант 1: all_of

Програма порівнює `std::all_of` без політики виконання, з `seq`, `unseq`, `par`, `par_unseq` та власний алгоритм із K потоками. Кожен потік перевіряє свою частину послідовності, після завершення потоків часткові результати об'єднуються через `std::all_of`.

Дані читаються з папки `data`: спочатку N, потім N цілих чисел через пробіли або переноси рядків. Досліджуються три довжини, перевірка додатності та простоти числа, випадки з усіма істинними значеннями й хибним елементом на початку або наприкінці. Час вимірюється після прогріву як медіана п'яти повторів. Програма виводить час кожного методу, найкращий перевірений K та його співвідношення з кількістю потоків процесора.

Повна реалізація має назву `lab2_v1`. Звіт міститься в `report.pdf`, скріншоти - у `screenshots`.
